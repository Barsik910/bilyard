# Бильярд «восьмёрка» по сети

Играть: https://barsik910.github.io/bilyard/

Американский пул (8-ball) в браузере, на компьютере и на телефоне.

- **По сети вдвоём.** Браузеры соединяются напрямую (WebRTC через PeerJS). По сети уходит только удар, физику каждый считает у себя. Друга можно позвать ссылкой.
- **Против бота**: лёгкий, средний или сильный.
- **На одном устройстве** вдвоём по очереди.
- Реакции и короткий чат, повтор последнего удара (можно в замедлении).
- Правила по желанию: заказ лузы для восьмёрки, обязательное касание борта, таймер на удар.

Вся игра — один файл `index.html`, без сборки и зависимостей. Библиотека PeerJS 1.5.5 (MIT) встроена в файл.
